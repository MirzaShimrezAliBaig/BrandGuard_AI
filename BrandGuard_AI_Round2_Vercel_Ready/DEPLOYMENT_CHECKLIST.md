- [ ] Deploy `index.html` to a public static hosting provider.
- [ ] Open the deployed URL in an incognito/private window.
- [ ] Confirm there is no sign-in requirement or access-protection screen.
- [ ] Test Load Risky Example -> Run Review -> Expand Finding -> Apply Fix -> Re-review -> Send for Human Review -> Approve/Request Changes/Reject.
- [ ] Check the Knowledge Vault and Settings.
- [ ] Create a public GitHub repository containing `index.html`, this README and technical notes.
- [ ] Submit the public project URL and public repository URL.
- [ ] Attach the updated project PDF.
- [ ] Include the completed-feature list, technology/implementation details, changes from Round 1 and three Round 3 improvements.
